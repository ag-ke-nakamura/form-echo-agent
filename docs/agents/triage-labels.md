# Triage Labels

スキル群は triage を5つの正規ロールで語る。このファイルは、そのロールをこのリポジトリの issue tracker で実際に使うラベル文字列に対応づける。

| mattpocock/skills でのラベル | このリポジトリでのラベル | 意味                                     |
| ---------------------------- | ------------------------ | ---------------------------------------- |
| `needs-triage`               | `needs-triage`           | メンテナが内容を評価する必要がある       |
| `needs-info`                 | `needs-info`             | 報告者からの追加情報を待っている         |
| `ready-for-agent`            | `ready-for-agent`        | 仕様が固まり、AFK エージェントに渡せる   |
| `ready-for-human`            | `ready-for-human`        | 人間による実装が必要                     |
| `wontfix`                    | `wontfix`                | 対応しない                               |

スキルがロール名で言及したとき（例「AFK 対応可の triage ラベルを付ける」）は、この表の対応するラベル文字列を使う。

語彙を変えたいときは右列を書き換える。
