## 仕様書: メモリー埋め込み検索

**版**: 1.0  
**ステータス**: 確定

### 概要

FormEchoAgent がユーザーの自然言語クエリを理解し、意味的に関連する過去のメモリーを効率的に検索・取得する機能。

### 主要ユースケース

#### UC-1: ユーザーが過去の会話から関連情報を引き出す

**主フロー**:
1. ユーザーが「3 週間前に相談した営業戦略について教えて」とリクエスト
2. Agent がクエリを埋め込みベクトルに変換
3. MemoryDB で意味的に近いレコード を K 件取得
4. 該当セッション の コンテキストを再構築
5. ユーザーに応答

### データモデル

```
MemoryRecord:
  - id: UUID
  - agent_id: FK
  - session_id: string
  - content: string (元のテキスト)
  - embedding: vector[1536] (OpenAI text-embedding-3-small)
  - created_at: timestamp
  - metadata: {role, source, tag}
```

### 受け入れ基準

- [ ] 埋め込み取得の平均レイテンシ < 100ms (K=10)
- [ ] 意味的適合性スコア > 0.8 (手動検証)
- [ ] メモリー容量 10,000 レコード以上に対応
